一个用于**离线暗黑破坏神3**主机版 **卡奈魔盒** 的配方查找器。选择一件物品以及你在意的词缀，它会尝试创造出能够用全新的赛季角色稳定产出该物品的配方。当然，你也可以在任何角色上使用生成出的物品。

该工具完全在浏览器中运行（Rust 编译为 WebAssembly），因此即使在手机上也能使用，且无需服务器。

## 使用方法

打开网站（用任意静态服务器打开 `web/index.html`，或直接访问 [GitHub Pages 部署](https://nzhijun.github.io/d3recipes/)），然后：

1. 选择软核或硬核以及赛季号（默认：软核，赛季 40）。
2. 选择一个职业、一件物品，以及（可选）一组词缀。
3. （可选）展开"成本与限制"区块，以定义搜索范围。
4. 点击**查找配方**。

**重要提示**：配方假定一个全新的、1 级、未进行过任何魔盒转换、也未获得过任何经验值的赛季角色。哪怕只是先进入剧情模式再进入冒险模式，或读了海德里格的日记，都可能足以破坏配方。

## 工作原理

该工具模拟了游戏生成物品的方式，因此所有结果都可以预先计算出来。

## 请求构筑预设

复制 `builds_template.toml` 中的区块，填入你收藏的物品（每个槽位一件物品，词缀优先从高到低），然后提交 issue 或在 PR 中将内容添加到 `builds.toml` 末尾。以能直接粘贴进该文件的格式提交的高质量构筑会被考虑，我们欢迎针对优秀构筑或有用的物品集合提交 PR。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `web/` | 静态网站（`index.html`、`app.js`、`builds.js`、`recipe.js`、`stats.js`、`worker.js`、`icons/`）、游戏数据表（`data.json`）、预生成的配方（`premade_sc.json`、`premade_hc.json`）以及编译好的 WebAssembly（`pkg/`） |
| `core/` | Rust crate：模型（`sim.rs`）、搜索（`plan.rs`）、数据表加载（`data.rs`）、wasm 接口（`lib.rs`）和测试 |
| `testdata/` | 测试使用的预期结果 |
| `docs/` | README 横幅和演示 |
| `builds.toml` | 预计算构筑列表（每个槽位的物品和词缀优先顺序） |
| `builds_template.toml` | 请求构筑的复制粘贴模板 |

修改 `core/` 后构建 wasm：

```
cd core
cargo test --release
wasm-pack build --release --target web --out-dir ../web/pkg
```

本地服务：`python -m http.server 8765 -d web`，然后打开 `http://localhost:8765`。
