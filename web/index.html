Before you start

Every recipe here assumes these. Skipping one is the usual reason a result doesn’t match.

  • Unlock primals first: clear a solo Greater Rift 70 on another hero of the same season and mode.
  • Use a fresh level 1 seasonal hero.
  • Don’t gain any XP, including in town by reading Haedrig’s book.
  • Don’t do any earlier transmutes on the slot.
  • Follow the steps in order.
  • Check each intermediate item against the stats shown, and stop if one doesn’t match.

Costs and Limits

Relative cost of one step of each kind. The search finds the recipe with the lowest total by these weights, so only the ratios matter.

How far the search may branch. Converts and hero swaps cost little, so each one more can find cheaper recipes but makes the search much slower. Leave a box empty for no limit. A hero swap hands the item to another class for a cube step: the item keeps its seed and the hero's class changes what it rolls. Any class may also create the item (each class's Hope of Cain picks and rolls differently), which counts as a hero swap; the later cube steps and the Mystic may be any class too.
