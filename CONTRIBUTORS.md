# Contributors

d3recipes is written by Fred N. Garvin (FNG) ([@FNGarvin](https://github.com/FNGarvin)).

Thank you to everyone else whose work is in it. People are listed in the order of their first contribution, and what each did is grouped by theme. Pull requests are numbered as on GitHub.

## szymonos ([@szymonos](https://github.com/szymonos))

The first outside contributor. Cross-class crafting and the Mystic's rules:

- **Heroes handing the item over.** Custom search can hand the item to a hero of another class between cube steps, and any allowed class may create the item, class items included (#5, #10).
- **Converting as another class.** A Convert by a hero of another class than the item's spends one extra draw (#13).
- **The Mystic follows the game.** The Mystic step checks the kind of roll and the enchanting hero's class, so it stops suggesting rolls the game would not give (#5).
- **Primal sockets.** Primal items always get all their sockets (#5).

## Ainahir ([@Ainahir](https://github.com/Ainahir))

Builds and Sanctification:

- **Edit builds and Search build items.** Save a build in the browser, import and export it as `builds.toml`, and search every slot at once (#6).
- **Seasonal Sanctification.** Angelic Crucibles in the seasons that have them, with their own price and limits, and the Sanctification and ashes rules for items of another class, each backed by in-game tests on whole sequences of results (#7).

## nzhijun ([@nzhijun](https://github.com/nzhijun))

The Chinese localization, with a fork that carries it:

- **The whole page in Chinese:** interface text, item, stat, class and material names, tooltips, and a Chinese README, with a language switch. The wording follows the console game's own terms (Sanctification as 圣化, for example).
- **A base for other languages.** The strings live in one table, which is where a further translation would start.
